照对标截图的做法：一个文件一枚胶囊（类型角标 · 文件名 · 大小），横排、放不下换行；有画面的文件用方块。没有外层卡片，直接跟在正文下面。

  • 不存在：虚线边框、划线、不可点，不用警示色（文件被移走是正常事）
  • 无法访问（第二枚）：读文件信息得到 403，原因本轮分不开（越界链接、没有读权限、系统拒绝），用中性说法，不用锁
  • 工作区外（第三枚）：外观与普通胶囊一致，大小是交付时的值；主操作是「在文件夹中显示」
  • 其他读取失败（5xx、网络）：胶囊照常，大小一格写「—」，点开由打开链路报错
  • 缩略图没到之前先显示占位方块，到了再换，尺寸不变
