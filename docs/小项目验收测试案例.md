# 小项目验收测试案例

本文档用于记录 `coding-agent` 成品后可用于实战验收的小项目案例。

这些案例不是单元测试，而是面向真实使用的“小型项目任务”。目标是验证 Agent 是否能独立完成代码量不大的完整项目，并覆盖文件读写、前后端协作、工具权限、错误处理、测试闭环和变更总结等核心能力。

## 推荐案例

### Todo 桌面小工具

功能范围：

- 增删改查 Todo。
- 本地 SQLite 保存。
- 支持搜索和筛选。

适合验证：

- 基础应用生成能力。
- 前后端协作。
- 状态管理。
- 数据持久化。
- 测试闭环。

### Markdown 笔记应用

功能范围：

- 新建、编辑、删除 `.md` 文件。
- 左侧文件列表。
- 右侧编辑和预览。
- 本地文件读写。

适合验证：

- 文件读取工具。
- 文件写入审批。
- UI 生成。
- 本地数据管理。
- checkpoint 和变更追踪。

### JSON 配置编辑器

功能范围：

- 打开一个 JSON 文件。
- 表单化编辑字段。
- 保存前校验 JSON schema。
- 校验失败时提示错误。

适合验证：

- 文件读写。
- schema 校验。
- 错误处理。
- 保存审批。
- 失败路径和回滚边界。

### 简单博客生成器

功能范围：

- 输入标题和正文。
- 生成 Markdown 文章。
- 自动更新文章列表页。
- 支持本地预览。

适合验证：

- 多文件修改。
- 项目结构理解。
- 内容生成。
- 变更总结。
- 预览和验证闭环。

### CSV 数据清洗小工具

功能范围：

- 选择或导入 CSV 文件。
- 去重、筛选、列重命名。
- 导出新 CSV。

适合验证：

- 数据处理。
- 工具调用。
- 文件输入输出。
- 边界数据处理。
- 日志和错误提示。

### 天气查询面板

功能范围：

- 输入城市。
- 调用天气 API。
- 展示最近几天结果。
- 处理网络失败或城市不存在。

适合验证：

- 网络访问权限。
- API 调用。
- 错误处理。
- 前端展示。
- 用户输入校验。

### Git 提交信息生成器

功能范围：

- 读取当前 diff。
- 生成 commit message。
- 支持中文和英文。
- 可选择不同提交风格。

适合验证：

- 项目上下文读取。
- 低风险工具执行。
- 规则遵守。
- 输出格式控制。

## 第一批推荐验收顺序

优先使用以下三个案例：

1. Todo 桌面小工具。
2. Markdown 笔记应用。
3. JSON 配置编辑器。

原因：

- 体量小，适合快速验收。
- 覆盖基础 app 生成、本地文件读写、schema 校验和错误处理。
- 能验证 Agent 是否能完成完整小项目，而不是只会聊天或改单文件。

## 验收观察点

执行这些小项目时，重点观察：

- Agent 是否能先理解需求并拆分任务。
- 是否会主动建立合理目录结构。
- 是否遵守项目技术栈和代码规范。
- 是否能正确使用工具，而不是绕过工具系统。
- 涉及写文件、网络、命令执行时是否进入权限边界。
- 是否能运行测试并根据失败结果修复。
- 是否能生成可读的变更总结。
- 是否能在失败时保留日志、事件和 checkpoint。
