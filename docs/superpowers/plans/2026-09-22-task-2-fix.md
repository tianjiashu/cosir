# Task 2 Child Agent Lifecycle Fix Implementation Plan

> **For agentic workers:** This plan is executed inline in the current session. Steps use checkbox (`- [ ]`) syntax for tracking; no Git commit is authorized.

**Goal:** Close the Task 2 P1/P2 lifecycle gaps so Child Agent close fences, follow-up mailbox delivery, canonical Run convergence, event-loop responsiveness, startup cleanup, ownership, ordering, and dependency reset are deterministic.

**Architecture:** Keep SQLite-backed Task/ConversationRun state canonical and keep the process-local session/mailbox registry behind one lock. Treat close as a generation fence; every asynchronous and synchronous launch phase revalidates that fence, while all synchronous canonical reads/writes from event-loop callbacks run through `asyncio.to_thread`. Preserve mailbox entries until claim and executor registration succeed, then remove them atomically; failures converge any created Run and leave the mailbox for bounded retry/sweep.

**Tech Stack:** Python 3, asyncio, SQLAlchemy-backed SQLite services, pytest/pytest-asyncio, Ruff, compileall.

## Global Constraints

- Only backend lifecycle code, related backend tests, the plan, and `task-2-fix-report.md` may change; do not modify frontend files.
- Do not commit Git changes.
- Every production change follows RED → GREEN; each new regression test must fail for the targeted pre-fix behavior before implementation.
- `ConversationRunStatus` remains the canonical Run lifecycle source of truth.
- Child Tasks must use `task_type="delegation"` and ownership checks must reject other task types.
- Do not silently probe repository-owned methods with `getattr(...)/callable`; missing child-session wiring must be explicit and observable.
