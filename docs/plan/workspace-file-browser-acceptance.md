# Workbench 工作区文件浏览器

实现日期：2026-10-17。

## 路线与边界

采用独立文件浏览模块，复用 Workbench 容器、React Arborist、React Symbols、CodeMirror 6、Streamdown、PDF.js 与现有 HTTP/日志/查询边界。没有把目录和预览分支堆进对话工具 renderer，也没有增加 Rust 文件业务 IPC。比在 Workbench 中直接拼接文件树与原生文件读取，这一结构让文件访问、资源生命周期和 UI 状态有独立且可测试的归属。

后端以 workspace ID 解析已登记根目录，磁盘是目录和内容的事实源。目录排序缓存仅放进程内或系统临时目录；不写 workspace，不把文件树持久化到业务 SQLite。前端只维护展开状态、预览页签、阅读位置及显示设置。关闭面板释放监听、网络读取、图片 URL、编辑器和 PDF worker；重新打开恢复当前进程内的阅读状态。

## 已实现的交互

- 工作区顶部“文件”入口；Workbench 中每工作区唯一文件面板。
- 虚拟目录树，按需枚举、自然排序、分页加载、隐藏文件、内部符号链接、链接状态提示、键盘导航、定位当前文件、折叠、刷新、复制路径。
- Python、JSON、配置文件等由 React Symbols 按文件名匹配图标；未知文件有通用图标。
- 全工作区文件名/路径/glob 搜索，不依赖目录展开；支持取消、重试、分页和无法扫描条目的明确提示。
- 单击临时预览，双击或按钮固定标签。所有内容只读，不提供文件编辑、新建、移动或删除接口。
- CodeMirror 语法高亮、选中复制、查找、跳转行、换行；编码选择；大文本双向分段、跳到末尾和全文件查找。分段行号为当前片段行号，字节位置显示在工具栏。
- Markdown 源码、预览与分栏；工作区相对链接和相对图片；相对图片加入共享实时监听。HTML 清理复用 Streamdown 默认插件；外部图片不自动联网加载。
- PNG/JPEG/GIF/WebP/BMP/AVIF/ICO/SVG 图片预览、缩放、适应面板；SVG 可切换源码。
- PDF.js 本地 worker、字体、CMap、WASM 随包发布；页面滚动、翻页、缩放、文本层、查找、密码输入与错误显示。资源支持单段 HTTP Range，多段 Range 按完整响应处理。

## 生命周期、路径与性能契约

原生 watchdog 监听按订阅共享目录 watcher，监听展开目录、打开文件的父目录和 Markdown 引用资源。通知只使查询失效。健康检查每 2 秒执行，原生不可用时明确显示周期同步；正常空闲每 15 秒校验一次以覆盖遗漏事件、休眠和目录重建。断线退避重连，后端端口换代自动取消旧连接。最后一个订阅关闭后停止 observer。

路径输入在后端边界校验。内部链接保留展示路径，禁止外部目标，祖先链检查阻止循环展开。内容在打开后检查实际句柄路径和普通文件类型；目录在 POSIX 使用已校验 fd 枚举，Windows 使用固定真实目录句柄，避免校验后替换链接。资源响应始终读取同一个已校验句柄。版本变化返回冲突，避免将不同版本内容拼接。

运行预算用于限制资源消耗，不限制可浏览文件数量：

| 内容 | 策略 |
| --- | --- |
| 单目录 | 前 10,000 条以内存排序；超过后落系统临时 SQLite 排序索引；分页返回，虚拟渲染 |
| 文件名搜索 | 流式遍历，单页 1,000 条，继续翻页可访问其余结果；翻页重新扫描当前磁盘 |
| 全文件匹配 | 增量解码和跨块匹配，单页 500 条，不将整个文件加载到浏览器 |
| 文本 | 2 MiB 内整体读取，较大文件按约 512 KiB 分段；超长单行关闭语法解析 |
| 非自同步编码 | GB18030/Big5/Shift_JIS 的随机位置从头增量定位正确字符边界，内存有界且可取消；超大旧编码文件定位耗时与前缀长度有关 |
| 图片 | 大于 1,600 万像素或 32 MiB 时生成最长边 4,096 像素缩略图；超过 8,000 万像素明确拒绝解码 |
| SVG | 超过 8 MiB 提示使用源码分段阅读 |

目录分页版本冲突会重新读取，搜索是可刷新的磁盘视图而非跨时间冻结的索引。目录扫描、排序和搜索支持取消；临时索引有过期与容量回收。日志记录目录耗时和监听降级，复用现有结构化落盘日志与 HTTP trace。

## 2026-10-17：Critique 修复验收

用户确认两项 A 方案：窄 Workbench 打开文件后优先阅读、目录可随时展开；Markdown 默认渲染预览，并分别记住各文件选择的模式。

本轮采用职责明确的布局与阅读状态调整，保留现有文件访问、资源加载和监听边界；没有通过逐条压缩字号或隐藏必要操作来补阅读空间。具体结果：

- 窄面板在浏览与阅读之间切换，宽面板保留可调目录；收拢默认常驻的编码、换行、文件元数据及搜索范围设置。目录展开时保留阅读组件，避免无意义销毁资源。
- CodeMirror 使用官方 One Dark 语法样式和现有明暗主题状态；主题切换通过 Compartment 更新，不重建编辑器。共享 Markdown 源码阅读器同步修复。
- 阅读偏好归 workspace 文件会话，每文件分别保存 Markdown 模式与换行；关闭标签再打开仍保留偏好。源码和 Markdown 预览分别保存滚动位置。偏好仅在当前应用会话内保留，移除工作区时清理。
- 文件标签与外层 Workbench 标签复用已安装 Radix Tabs，提供方向键/Home/End 导航和 ARIA 关联。固定、关闭、目录工具按钮扩大命中范围并补齐 tooltip；关闭文件后主动移交焦点。
- 全文件查找快捷键覆盖文件标签与正文，活动文本阅读器注册动作，快捷键仅作用于阅读区域；不接管整个窗口。编码或文件版本变化取消旧搜索；取消后的迟到批次不更新结果。
- 文件名搜索仅在运行时显示停止，停止/失败可重试；空结果提供清空与返回目录；分页按实际需要出现。默认仍搜索整个工作区，常见依赖目录由用户显式排除。
- 后端搜索按受控原因聚合未扫描条目，前端可展开查看；保持 HTTP schema 与 service 分工。复制路径提供成功反馈，文件行不再带无意义的目录展开按钮。

## 2026-10-17：文件浏览器忽略

采用浏览用例统一过滤，而非文件树和搜索各自维护前端隐藏名单。工作区的 `.cosir/file-browser.json` 是浏览忽略配置的唯一持久化来源；复用 `ConfigurationFileStore` 的锁和原子替换。读取缺失配置不创建文件，首次忽略才落盘。Agent 的 `.fileignore`、`.gitignore` 和工具搜索链路不消费此配置。

- 文件树和文件名搜索结果支持右键忽略、Ctrl/Cmd 多选忽略及 Shift+F10 菜单。目录按精确展示路径忽略整棵子树，普通路径中的通配符按字面处理；链接与其实际目标分别设置。
- 后端在目录排序分页前过滤，搜索遇到隐藏目录不进入子树；目录分页绑定规则版本。配置更新使前端目录查询换代、搜索从第一页重启，迟到的搜索批次不回填旧结果。`@` 文件/目录候选复用相同的搜索契约。
- 忽略后通过统一通知提供撤销；只撤销本次实际新增的规则。更多菜单提供“管理忽略项”，可筛选路径并恢复显示。全部内容被忽略的目录有解释与管理入口。现有临时搜索排除继续生效，清除临时条件不会清除持久化忽略。
- 已打开标签、阅读位置、文件内容读取和历史引用保留。忽略是界面发现范围设置，不是文件访问权限，也不修改 Agent 行为。恢复父目录不会删除子项原有的独立忽略规则。
- `.cosir` 存在时纳入现有非递归监听；规则查询按现有周期校验节奏补偿首次创建及漏事件，`@` 单独使用时也会刷新。未新增监听服务或前端持久化事实。
- 复用现有 Radix 菜单、Dialog、语义色彩、Lucide 图标和 `notify`；通知层仅增加成功操作的撤销按钮能力。相关修复包括 @ 关闭标记随输入变化重置，以及 Portal 菜单键盘事件与树导航隔离。

验证：后端浏览与忽略专项 39 项、前端文件/引用单元测试 26 项、Chrome/WebKit 忽略专项 6 项通过，最终文件浏览与引用相关回归合计 24 项通过（含这 6 项）；浅深色菜单与管理弹窗已做截图检查。TypeScript、定向 ESLint、Ruff 和生产构建通过。已有 `test_search_tools.py` 三项内部契约测试仍调用旧参数或旧 monkeypatch 路径，未修改无关 Agent 实现来适配；新增测试直接调用实际 `FindFilesTool` / `SearchContentTool`，验证浏览忽略不影响 Agent。未进行 Windows/WebView2 真机或 Tauri 安装包验收。
